# App shell rebuild rules

- Aesthetic = Stitch-light marketing DNA (white bg, solid violet `#7c3aed`, Manrope, ambient violet-300/400 glows, violet-200 borders, flat violet CTAs).
- Feel = generative + streaming. Numbers, narratives, charts animate into existence (framer-motion, count-up, stream-in). Nothing static or grid-y.
- Hide ALL technical chrome: no agent IDs, no DO instance names, no tick counters, no terminal feeds, no JSON, no "log" / "decisions" panels, no monospace data tables. The agent system is invisible.
- Speak in human outcomes: "Your treasury earned $X this week", "Dreyv noticed Y and recommends Z", not "subagent:abc tick fired at T".
- One continuous brand with `/pricing`, `/waitlist`, `/`. Same fonts, same violet, same glow language.
- No dark mode for these pages on first pass.
