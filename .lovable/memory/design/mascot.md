Brand mascot: **Dreyv**, an owl-fox hybrid treasury sentinel. The mascot shares the brand name (no separate persona name).
- Color: solid violet `#7c3aed` body, deeper violet shading, cream chest/brow accents. NO gradients, NO fuchsia. Amber `#f59e0b` reserved for the chest "status dot" on alert pose only.
- Tone: calm, watchful, dignified — never cute/childish. Founder-to-founder energy.
- Style: flat illustration, clean vector lines, subtle cel-shaded depth. Premium tech-brand mascot quality (Linear/Vercel/Stripe tier).
- Poses (all transparent PNG 1024×1024) in `src/assets/mascot/` and mirrored to `public/mascot/`:
  - `dreyv-greet.png` — welcome / onboarding
  - `dreyv-think.png` — empty states, loading, AI thinking
  - `dreyv-celebrate.png` — success, milestone, payment
  - `dreyv-alert.png` — warnings, anomalies, action required
- When adding new poses: keep silhouette/proportions/palette consistent. Generate via imagegen `premium` with explicit "same character, same proportions, same palette as existing set".
