DB migration runner

Lists every .sql file under db-migrations/ and migrations/sql/, and runs them statement-by-statement against DATABASE_URL. This page is a static HTML file outside the app, so no login, wallet, or React providers load here. Migrations should be idempotent.

Listing migrations does not require the key; the key is required only to execute SQL and is stored only in this browser via localStorage.
